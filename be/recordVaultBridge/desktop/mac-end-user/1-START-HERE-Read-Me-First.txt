========================================================
  usbBridgeV3 for Mac — START HERE
  (After you clicked “Download usbbridge zip” on the website)
========================================================

You do NOT need Terminal commands typed by hand.
Use Finder clicks and normal Mac buttons.


BEFORE THE 4 STEPS — Unzip the download
---------------------------------------
  1. Open Finder → Downloads
  2. Double-click:  usbBridgeV3-mac.zip
     (This creates a folder named usbBridgeV3-mac)
  3. Open that folder. You should see:
       • 1-START-HERE-Read-Me-First.txt   (this file)
       • 2-Open-Privacy-Settings.command
       • usbBridgeV3.app

  If you still see “2-Open-Privacy-Settings.webloc” (old zip),
  delete that folder and download again from the website.


Why Mac shows a warning
-----------------------
This app is not yet signed with an Apple certificate.
macOS blocks it the first time. That is normal.


EASIEST PATH (try this first on newer macOS)
--------------------------------------------
  1. Control-click (right-click) usbBridgeV3.app
  2. Choose:  Open
  3. In the dialog, click:  Open
  4. Look for a small icon in the menu bar (top of screen)

  If that worked, you are done — skip Steps 1–4 below.


STEP 1 — Try to open the app (registers the block with macOS)
-------------------------------------------------------------
  • Double-click:  usbBridgeV3.app

  • A warning appears (Apple could not verify … malware).
  • Click:  Done
    (Do NOT click “Move to Trash”.)


STEP 2 — Open Privacy & Security settings
-----------------------------------------
  • Double-click:

      2-Open-Privacy-Settings.command

  • If Mac asks whether to open Terminal / allow the script, click Open / Allow.
  • System Settings should open to Privacy & Security.

  • If nothing useful opens, do this manually:
      Apple menu → System Settings → Privacy & Security


STEP 3 — Allow the app
----------------------
  • Scroll to the BOTTOM of Privacy & Security.
  • You should see that usbBridgeV3 was blocked.
  • Click:  Open Anyway
  • Approve password / Touch ID if asked.
  • If it asks again to open, click:  Open


STEP 4 — Open the app again
---------------------------
  • Double-click:  usbBridgeV3.app  again

  • Look for a small icon in the menu bar (top of screen).

  • Go back to the website (Photo Albums or Notes → USB).
    Status should turn green: “USB Connected & Ready”.


Next time
---------
Just double-click usbBridgeV3.app. You should not need
the allow steps again.

Need help?
----------
• “webloc / document not readable” → you have an old zip. Download again.
• No “Open Anyway” → finish Step 1 first (Done, not Trash), wait a few
  seconds, then open Privacy & Security again.
• Still blocked → use the EASIEST PATH (Control-click → Open).
